# 검증 도구

## 준비

```bash
npm install puppeteer-core
```

## 실행

```bash
# 1) 앱 폴더에서 로컬 서버 실행
python3 -m http.server 8000

# 2) 다른 터미널에서
node tools/verify.js 8000
```

크롬 경로가 다르면 환경변수로 지정합니다.

```bash
CHROME_PATH="/path/to/chrome" node tools/verify.js 8000
```

## 검사 항목

| 항목 | 내용 |
|---|---|
| 데이터 무결성 | 빈 갈래, 동의어 목록 불일치, 뜻 누락 |
| 따라쓰기 전수 | 14,102개 전부 — 대상 생성, 칩 개수·중복 |
| 퀴즈 키보드 진행 | 숫자키·Enter로 10문제 연속 진행 |
| 주요 기능 | 약점·동기화·메모·역방향·손글씨·달력·다이어리·비슷한단어 |
| 선지 개수 규칙 | 6~9개 범위 유지 |

전부 통과하면 `✅ 전체 통과`, 하나라도 실패하면 종료 코드 1을 반환합니다.
